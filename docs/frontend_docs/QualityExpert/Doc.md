# Quality Expert Cabinet Requirements

## Назначение кабинета

Кабинет эксперта покрывает нормоконтроль, проверку ПО и антиплагиат.

## Разделы кабинета

1. Очередь проверок.
2. Карточка проверки по работе.
3. Вынесение решения (`Зачет/Незачет`).
4. История попыток и комментариев.
5. Уведомления.

## Основные сценарии

1. Эксперт открывает pending-список работ по своему типу проверки.
2. Загружает материалы, анализирует и фиксирует результат.
3. При `Незачет` формулирует требования к доработке.
4. Повторно проверяет новую попытку.

## Функциональные требования

1. Очередь должна фильтроваться по типу проверки и учебному году.
2. Карточка должна показывать предыдущие попытки и текущий статус.
3. Для антиплагиата обязательна запись процента оригинальности.
4. Должна быть поддержка прикрепления документа результата.

## Нефункциональные требования

1. Быстрый доступ к материалам (preview/download).
2. Стабильная работа с длинными текстовыми комментариями.

## Права и ограничения

1. Эксперт не управляет периодами и комиссиями.
2. Эксперт работает только с назначенными ему проверками.

## Definition of Done

1. Эксперт завершает полный цикл проверки в кабинете.
2. Все решения и комментарии корректно отображаются студенту/кафедре.
