# Commission Secretary Cabinet Requirements

## Назначение кабинета

Кабинет секретаря комиссии отвечает за организацию сессий, согласование оценок и формирование протоколов.

## Разделы кабинета

1. Мониторинг сессии предзащиты.
2. Посещаемость и попытки.
3. Reconciliation и финализация предзащиты.
4. Протоколы предзащиты.
5. Reconciliation и финализация защиты.
6. Протоколы защиты.

## Основные сценарии

1. Секретарь отмечает явку и контролирует заполнение оценок.
2. Запускает предварительное согласование.
3. Финализирует результат сессии.
4. Формирует протокол/ведомость.

## Функциональные требования

1. Должен быть дашборд заполненности оценок по каждому студенту.
2. До финализации отображать предупреждение о неполных оценках.
3. Протокол формировать по кнопке и сохранять ссылку на документ.

## Нефункциональные требования

1. Устойчивый сценарий работы в день защиты (без потери данных формы).
2. Логи действий по финализации.

## Права и ограничения

1. Секретарь не меняет состав комиссии и периоды.
2. Финализация доступна только в назначенных сессиях.

## Definition of Done

1. Секретарь закрывает сессию от начала до протокола внутри кабинета.
2. После финализации оценки блокируются в UI.
