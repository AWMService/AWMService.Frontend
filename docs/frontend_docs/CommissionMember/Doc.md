# Commission Member Cabinet Requirements

## Назначение кабинета

Кабинет члена комиссии покрывает оценивание на предзащите и защите.

## Разделы кабинета

1. Расписание предзащит.
2. Оценивание предзащиты.
3. Расписание защит (ГАК).
4. Оценивание защиты.
5. Просмотр материалов работы.
6. Уведомления.

## Основные сценарии

1. Член комиссии открывает список студентов на сессию.
2. Просматривает материалы и выставляет оценки по критериям.
3. При необходимости корректирует оценки до финализации секретарем.

## Функциональные требования

1. Форма оценки должна строиться динамически из `evaluation/criteria`.
2. Сохранение оценки — независимое по каждому критерию.
3. Видимость чужих оценок включается только после старта reconciliation.

## Нефункциональные требования

1. Минимальное количество кликов для выставления оценки.
2. Устойчивость к потере сети во время заседания.

## Права и ограничения

1. Член комиссии не финализирует протокол.
2. Нет доступа к админ-настройкам кафедры.

## Definition of Done

1. Оценивание по всем назначенным сессиям доступно в одном кабинете.
2. Все сохраненные оценки отображаются после перезахода.
