# Secretary/OR Manager Cabinet Requirements

## Назначение кабинета

Кабинет секретаря/менеджера ОР контролирует сроки, формирует списки на предзащиту/защиту и печатные документы.

## Разделы кабинета

1. Мониторинг готовности по кафедрам.
2. Списки допущенных к защите.
3. Расписание предзащит и защит.
4. Протоколы и ведомости (предзащита/защита).
5. Контроль дедлайнов и напоминания.

## Основные сценарии

1. Контролировать прогресс работ и проблемные кейсы.
2. Формировать и выгружать списки допущенных.
3. Печатать протоколы/ведомости.
4. Отправлять напоминания участникам.

## Функциональные требования

1. Дашборд с фильтрами по кафедре и учебному году.
2. Просмотр слотов и назначений по комиссиям.
3. Быстрые кнопки генерации/скачивания протоколов.
4. Массовая отправка reminder уведомлений.

## Права и ограничения

1. Нет права изменять академические решения комиссии (оценки).
2. Нет права менять состав НР и глобальные настройки системы.

## Definition of Done

1. Секретарь/ОР может закрыть организационный цикл по документам без ручной выгрузки из БД.
