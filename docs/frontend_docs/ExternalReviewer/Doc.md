# External Reviewer Cabinet Requirements

## Назначение кабинета

Внешний рецензент в базовом workflow обычно работает вне системы (email), но при наличии доступа может использовать упрощенный кабинет для загрузки рецензии.

## Разделы кабинета

1. Назначенные на рецензию работы.
2. Карточка работы и требования к рецензии.
3. Загрузка подписанной рецензии.

## Основные сценарии

1. Рецензент получает материалы, готовит отзыв, подписывает и отправляет.
2. Документ рецензии попадает в систему и отражается в статусах работы.

## Функциональные требования

1. Минимальный сценарий: загрузка файла рецензии + комментарий.
2. Просмотр базовых данных работы и контактов кафедры.

## Нефункциональные требования

1. Максимально простой UI без лишних разделов.
2. Поддержка больших PDF-сканов.

## Права и ограничения

1. Рецензент не имеет доступа к оценкам комиссии и внутренним этапам кафедры.
2. Доступ только к работам, где он назначен рецензентом.

## Definition of Done

1. Рецензент может загрузить рецензию без участия администратора.
2. Статус рецензии обновляется в кабинете студента/кафедры.
