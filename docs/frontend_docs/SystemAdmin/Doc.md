# System Admin Cabinet Requirements

## Назначение кабинета

Кабинет системного администратора управляет справочниками, организационной структурой, пользователями и служебными настройками.

## Разделы кабинета

1. Институты и кафедры.
2. Уровни образования, программы, типы работ.
3. Пользователи и сотрудники.
4. Студенты.
5. Служебный мониторинг API/интеграций.

## Основные сценарии

1. Ведение справочников и оргструктуры.
2. Поддержка данных сотрудников и студентов.
3. Управление нагрузкой сотрудников (при необходимости).

## Функциональные требования

1. CRUD-операции по справочникам с подтверждением удаления.
2. Поиск и фильтрация в больших таблицах.
3. Безопасные формы изменения данных с валидацией.

## Права и ограничения

1. Системный администратор не принимает академические решения (оценки, утверждение тем).

## Definition of Done

1. Базовые справочники и пользовательские данные обслуживаются через админ-кабинет.
