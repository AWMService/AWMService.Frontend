# Supervisor Cabinet Requirements

## Назначение кабинета

Личный кабинет НР покрывает управление направлениями, темами и заявками студентов, а также формирование отзыва.

## Разделы кабинета

1. Мои направления.
2. Мои темы.
3. Заявки студентов.
4. Закрепленные работы.
5. Отзывы НР.
6. Уведомления.

## Основные сценарии

1. НР создает направление и отправляет кафедре.
2. НР создает темы в утвержденных направлениях и пакетно отправляет на согласование.
3. НР принимает или отклоняет заявки студентов.
4. НР закрывает тему по достижении лимита участников.
5. НР загружает отзыв на закрепленную работу.

## Функциональные требования

1. Обязательная мультиязычность полей названий (RU/KZ/EN), минимум RU.
2. Явные статусы направлений и тем.
3. Очередь заявок по темам с фильтрацией по статусу.
4. Для отклонения заявки обязательна причина.
5. Для отзыва НР поддержать текст + файл.

## Нефункциональные требования

1. Кабинет должен корректно работать при большом количестве тем и заявок.
2. Все массовые действия сопровождать подтверждением.

## Права и ограничения

1. НР управляет только своими направлениями и темами.
2. НР не имеет доступа к административным периодам и комиссиям.

## Definition of Done

1. НР полностью ведет свои направления/темы/заявки через UI.
2. Изменения сразу отражаются в статусах.
3. Нет действий вне зоны ответственности роли.
