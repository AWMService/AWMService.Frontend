# Vice Rector (UR) Cabinet Requirements

## Назначение кабинета

Кабинет проректора по УР дает сводную аналитику по институтам/кафедрам и контроль выполнения workflow.

## Разделы кабинета

1. Сводный дашборд по институтам и кафедрам.
2. Готовность к защите (агрегировано).
3. Статусы рецензий/проверок.
4. Реестр работ и расписаний.

## Основные сценарии

1. Просмотр динамики готовности по подразделениям.
2. Выявление отстающих кафедр/групп.
3. Контроль количества допущенных и итоговых результатов.

## Функциональные требования

1. Фильтры по: институт, кафедра, учебный год, тип работы.
2. KPI-блоки: total works, ready/not ready, admitted.
3. Drill-down до уровня кафедры и списка работ.

## Права и ограничения

1. Роль аналитическая: без права менять оценки и workflow-состояния.

## Definition of Done

1. Проректор видит целостную картину по всем подразделениям в одном кабинете.
